# ChapFlow 界面文案规范

本文件规定界面文字的统一叫法、句式与标点。**新增或修改界面文案时以此为准**，
避免同一功能出现多种说法。技术含义与功能逻辑不受本规范约束。

---

## 1. 术语表（唯一叫法）

| 概念 | 统一叫法 | 不再使用 |
|---|---|---|
| 一个 EPUB 文件 | **书籍** | 书、文件（指书籍时） |
| 正在编辑的书籍 | **当前书籍** | 当前书、这本书 |
| 合并时作为主体的书籍 | **主书** | 主书籍、母书 |
| 待合并的其他书籍 | **待合并书籍** / **其他书籍** | 其它书、别的书 |
| 目录中的一项 | **目录项** | 条目、项、节点 |
| 目录树中的分组节点（无正文） | **大标题** | 分组、卷（指分组节点时） |
| 层级关系 | **一级标题 / 二级标题** | 一级条目、第一层标题 |
| 有正文的一章 | **章节** | 章、篇目 |
| 章节正文文件 | **正文文件** | 内容文件、HTML 文件 |
| 阅读顺序（OPF spine） | **阅读顺序**，必要时写 **spine** | 翻页顺序（口语）、顺序表 |
| 结构校验 | **校验** | 自检、检查（指校验功能时） |
| 校验结果 | **通过 / 警告 / 错误** | 正常、提示、异常 |
| 书籍元数据 | **元数据** | 属性、信息（混用时） |
| 书籍信息页 | **书籍信息** | 属性页、详情页 |
| 从 TXT / DOCX 导入章节 | **追加章节** | 导入章节、添加章节 |
| 直接输入正文建章 | **新建章节**（原「添加章节」） | 添加章节、手工加章 |
| 调整章节编号 | **编号** / **重新编号** | 排序、重排号 |
| 清理标题分隔符 | **规范章节名** | 只规范章节名、整理标题 |
| TXT / DOCX 转新书 | **格式转换** | 转换书、新建书（指该功能时） |
| 多本 EPUB 合并 | **合并书籍** | 拼接、合成 |
| 生成 .epub 文件 | **导出 EPUB** | 输出、保存为文件 |
| 覆盖当前文件保存 | **保存** | 存盘、写回 |

> 「大标题」指分组节点，「一级标题」指层级，两者不可互换：
> 新建分组叫「新建大标题」，把下级条目提到顶层叫「升为一级」。

## 2. 语气与句式

1. **书面语**，不用口语助词与含混表达。禁用：「就行」「一下就」「一眼」「看看」
   「点它」「弄」「搞」「呗」「吧」「嘛」。
2. **动作用「点击」，不用「点」「点一下」「点开」**；指向界面元素时用「点击「保存」」。
3. **指向当前界面用「此处」，指向左侧面板用「左侧目录」**，不用「这里」「那边」。
4. **提示语给出"做什么 + 会怎样"**，避免只说现象：
   - ✗ 「翻着翻着跳到别的书」
   - ✓ 「可能导致翻页顺序错乱」
5. **否定用「取消勾选」**，不用「不勾选」「去掉钩」。
6. **推荐项写「建议勾选」**，不用「推荐」「最好」。
7. 说明性括号里的补充用全角括号；示例写法用中文引号「」。

---

## 3. 标点与排版

- 中文句内标点一律全角：，。；：「」（）—— 不用 , . ; : "()
- 并列项之间用顿号「、」；分句之间用分号「；」
- 数字与中文之间不加空格（如「3 章」），单位与拉丁字母前后加半角空格（如 `TXT / DOCX`、`merged/bN/`）
- 状态摘要用「 · 」分隔，如 `EPUB 3.0 · 12.4 MB`
- 省略号用「…」（单个字符），按钮文案结尾不加省略号以外的标点

## 4. 控件文案

| 类型 | 规则 | 示例 |
|---|---|---|
| 按钮 | 动宾短语，2–5 字；危险操作用具体动作 | 保存、导出 EPUB、规范章节名、删除… |
| 菜单项 | 打开对话框的以「…」结尾 | 追加章节（TXT / DOCX）… |
| 输入框占位 | 说明可输入什么，不写命令 | 在此输入或粘贴章节正文… |
| 悬停提示 | 一句话说明「作用 + 影响范围」 | 折叠全部目录项，仅显示一级标题 |
| 空状态 | 标题 + 一句操作指引 | 尚未打开书籍 / 打开 EPUB 以编辑目录 |
| 统计标签 | 名词短语，不加冒号 | 目录项、正文页数（阅读顺序）、目录来源 |
| 日志 | 动词开头 + 结果 | 已导出（原文件未修改）、校验：2 错误 1 警告 |

## 5. 已统一的常见差异

| 统一前 | 统一后 |
|---|---|
| 自检报告 / 自检结论 | 校验报告 / 校验结论 |
| 目录来自 | 目录来源 |
| 目录条目 / 条目 | 目录项 |
| 添加章节 | 新建章节 |
| 其它 | 其他 |
| 未改动（原子写盘） | 未改动（原子写入） |
| 预览（不落盘） | 预览（不写入） |
| 正在自检… | 正在校验… |
| spine 兜底 | spine 回退 |
